CARA DEPLOY GRATIS 24 JAM DI RAILWAY:

1. Buka railway.app -> Login pake Github
2. New Project -> Deploy from GitHub / Upload
3. Upload folder ini
4. Pergi ke Variables -> New Variable, tambahin 3 ini:
   BOT_TOKEN = token dari @BotFather
   BOT_USERNAME = username bot kamu tanpa @
   ADMIN_ID = ID kamu dari @userinfobot

5. Klik Deploy. Selesai. Bot langsung online 24 jam.

Cara pake:
- Kamu kirim video ke bot -> bot balas link t.me/xxx?start=yyy
- Share link itu ke channel/grup lain.
- Orang klik -> auto dikirim videonya.
